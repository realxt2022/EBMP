Project Summary: Emotion-Based Music Player 🎵
Overview
The Emotion-Based Music Player is an innovative web application that uses facial emotion recognition to curate and play music based on the user's current mood. By leveraging a webcam feed and emotion detection algorithms, the application dynamically adjusts the background theme and plays songs that match the detected emotion. This project combines modern web technologies, machine learning, and user interaction to create a personalized and engaging music experience.

Key Features
Emotion Detection via Webcam:

The application uses the webcam to capture the user's facial expressions.
A machine learning model processes the captured frame to detect emotions such as Happy, Sad, Angry, and Relaxed.
Dynamic Backgrounds:

The background gradient changes dynamically based on the detected emotion, enhancing the visual experience.
Example:
Happy: Yellow to Orange gradient.
Sad: Blue gradient.
Angry: Red gradient.
Relaxed: Green gradient.
Emotion-Based Music Playback:

A curated playlist is associated with each emotion.
The application plays songs that match the detected emotion, creating a personalized music experience.
Webcam Preview Toggle:

Users can toggle the webcam preview on or off without affecting the emotion detection functionality.
The webcam runs in the background for emotion detection even when the preview is disabled.
Day/Night Theme Toggle:

Users can switch between day and night themes.
The footer text dynamically adjusts its color based on the theme and emotion:
For Happy: Black text in day mode, White text in night mode.
For other emotions: Default styling.
Music Player Controls:

Play/Pause, Next, and Previous buttons for song control.
Volume slider for adjusting playback volume.
A progress bar displays the current playback position.
Responsive Design:

The application is fully responsive and works seamlessly across devices.
Technologies Used
Frontend:

HTML5: Structure of the web application.
CSS3 (TailwindCSS): Styling and responsive design.
JavaScript: Dynamic functionality and user interaction.
Backend:

Flask: Python-based web framework for handling server-side logic.
DeepFace: Machine learning library for facial emotion recognition.
Media:

Webcam API: Captures live video feed from the user's webcam.
HTML5 Audio: Plays music files dynamically based on the detected emotion.
How It Works
Emotion Detection:

The user clicks the "Detect Emotion" button.
The webcam captures a frame, which is sent to the server for emotion analysis using the DeepFace library.
The detected emotion is returned to the frontend.
Dynamic Updates:

Based on the detected emotion:
The background gradient changes.
A song from the corresponding playlist starts playing.
The footer text color adjusts dynamically.
User Interaction:

Users can toggle the webcam preview, switch themes, and control music playback.
Use Cases
Personalized Music Experience:
Automatically plays music that matches the user's mood.
Interactive Learning:
Demonstrates the integration of machine learning with web development.
Entertainment:
Provides an engaging and visually appealing music player.

Conclusion
The Emotion-Based Music Player is a creative and practical application that showcases the power of combining machine learning with web technologies. It provides a unique, personalized music experience while demonstrating the potential of emotion recognition in real-world applications.
